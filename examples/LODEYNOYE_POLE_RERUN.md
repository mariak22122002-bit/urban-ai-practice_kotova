## Найденные расхождения и исправления

1. **HTML устарел относительно генератора.** В нём отсутствуют перечисленные выше
   диаграммы, таблицы и городские доли. В генераторе уже предусмотрены основные разделы;
   дополнительно включены точные таблицы частот морфотипов и 15 кварталов с наибольшим
   необеспеченным спросом. Существующий HTML обновится при вашей сборке.
2. **Экспорт терял подготовленные поля.** `combine-results` теперь присоединяет восемь
   полей землепользования и три поля привязки по `block_id`; проверяются наборы ID и
   совпадение ведущей функции. Это перенос готовых атрибутов, без перерасчёта метрик.
3. **Школьная модель ещё относится к старой выборке.** В `prepared/schools.geojson`
   присутствует художественная школа №5, OSM node `381843073`, с 250 оценочными местами.
   Текущий код её исключает, но сохранённые 6 объектов, 1500 мест и 83,01% получены до
   исключения. Для обновления нужна цепочка ячеек ниже. Если прочие объекты не менять,
   ожидаются 5 объектов и 1250 модельных мест; новую обеспеченность должен дать расчёт.
4. **Восстановление могло смешать сценарии.** `restore-saved-results` теперь восстанавливает
   прежние исключения из паспорта/метаданных подготовки. Новая ячейка `school-scenario`
   явно выбирает исправленную выборку. `save-summary` проверяет соответствие настроек
   подготовленному списку перед сохранением паспорта.
5. **Старые статусы Spacematrix и малая погрешность доли достижимости.** Старый CSV
   пишет «рассчитан для застроенных кварталов» даже для пустых кварталов; текущий §6
   различает «рассчитан» и «не применим», в том числе при недостатке кварталов для
   кластеризации. Версия статусов в ключе кэша обновлена, поэтому старый кэш будет
   заменён при выполнении §6. В сохранённом `reachable_area_share`
   встречается `1.0000000000000004`; текущий §10 уже ограничивает долю диапазоном [0, 1].
   Эти исправления попадут в результаты после выполнения §6 и §10.
6. **Представление чисел.** Генератор сохраняет дробную точность долей функций,
   `share_living` и `share_non_living`; кластер — категория. Число интервалов гистограмм
   приведено к правилу ноутбука `min(20, число определённых значений)`. Диаграммы и
   квартальная таблица учитывают фильтры; обзор, сохранённые таблицы и паспорт — весь город.
7. **Дата графа.** `source_date = 2026-11-07` в старом паспорте — дата создания графа
   через OSMnx, подтверждённой даты снимка OSM нет. Генератор объясняет старую запись;
   восстановление переносит её в `graph_created_at`. Новый паспорт запишет это после §13.
8. **Повторяемость.** При экспорте обновляется `manifest.json`. При вашей сборке HTML
   выполняются проверки CSV/GeoJSON, формул плотности, школьных балансов и округления
   спроса, взвешивания времени, входных контрольных сумм, подготовленных полей,
   статистик, частот морфотипов и паспорта. При расхождении HTML не перезаписывается.

Сохранённые `observations` пусты, `route_checks.csv` содержит только заголовок.
Подтверждённых ручных проверок маршрутов в снимке нет. В `quality_checks.csv` также
указаны 3320 зданий с неизвестным назначением и 3568 с восстановленной этажностью.

## Повторный запуск на сохранённых данных

Команды ниже выполняете **вы**, из корня `python-package-boilerplate`, в уже установленном
окружении. Установка пакетов и новый граф для этих действий не нужны.

### 1. Открыть ноутбук и прочитать снимок

```bash
source .venv/bin/activate
python -m jupyter notebook examples/lodeynoye_pole.ipynb
```

Выберите ядро проекта и **Kernel → Restart Kernel**. Выполните четыре кодовые ячейки:

1. `environment` — в разделе 0, начинается с `import hashlib`.
2. `settings` — начинается с `PLACE_QUERY = ...`.
3. `storage-functions` — начинается с `def file_hash(path):`.
4. `restore-saved-results` — раздел 0.1, начинается с чтения `summary.json`.

Настройки локального прохода:

```python
LOCAL_DATA_ONLY = True
SHOW_INTERACTIVE_MAPS = False
FORCE_DOWNLOAD = False
FORCE_RECALCULATE = False
```

`restore-saved-results` читает файлы и восстанавливает переменные. Отсутствующий исходный
слой при `LOCAL_DATA_ONLY = True` приводит к остановке, а не к сетевому запросу.
Не используйте **Run All**: после восстановления нужен выбранный маршрут ниже.
Старые сохранённые выводы Folium могут обращаться к CDN и тайлам уже при открытии
ноутбука. Для полностью автономного просмотра используйте HTML; для локального
прохода в Jupyter очистите старые выводы через **Clear All Outputs**. Флаг
`SHOW_INTERACTIVE_MAPS = False` отключает создание карт Folium, включая отдельную
карту привязки квартала 69. Если привязки ещё не подготовлены, эта отдельная ячейка
предлагает сначала выполнить `snap-blocks` или восстановление снимка.

### 2. Перенести пропущенные поля в HTML, сохранив прежние расчёты

После четырёх ячеек выполните **только §11 `combine-results`**. Затем создайте HTML
командой из последнего раздела. В экспорте появятся доли функций и привязки к сети,
но школьные числа, статусы морфотипов и паспорт останутся от сохранённого расчёта.

### 3. Обновить школьную выборку и зависимые результаты

После четырёх стартовых ячеек выполняйте в таком порядке:

| Порядок | Раздел / ячейка | Что происходит |
|---|---|---|
| 1 | §4 `analysis-imports` | Импортируются функции BlocksNet, необходимые после перезапуска ядра |
| 2 | §4.3 `school-scenario` | Выбирается исключение художественной школы после восстановления старого сценария |
| 3 | §4.3 `prepare-schools` | Из локального `raw/schools.geojson` готовится исправленный список |
| 4 | §4.3 `school-confirmation` | После просмотра списка задайте `SCHOOLS_REVIEWED = True` и выполните ячейку |
| 5 | §4.4 `aggregate` | Обновляется квартальная модель с новым числом школ и вместимостью |
| 6 | §5 `density` | Обновляются таблица плотности и её зависимость от модели |
| 7 | §6 `morphotypes` | Обновляются морфотипы, центры кластеров и корректные статусы |
| 8 | §9 `provision` | На сохранённой матрице времени пересчитывается распределение мест |
| 9 | §10 `area-accessibility` | Обновляются доступность и ограниченная диапазоном доля достижимой площади |
| 10 | §11 `combine-results` | Перезаписываются итоговые GeoJSON, CSV, словарь и контрольные суммы |
| 11 | §11.1 `charts-and-tables` | Обновляются статистики, частоты, PNG и городские strong/weak |
| 12 | §12 `quality-checks` | Сохраняются проверки качества и проверяется чтение GeoJSON обратно |

| 14 | §13 `save-summary` | Записываются актуальные параметры, выводы, паспорт и итоговый manifest |

При неизменённых исходниках изменённые параметры инвалидируют нужные кэши сами:
`FORCE_RECALCULATE = False` оставьте выключенным. §1–3, §4.1–4.2 и §7–8 повторять
не требуется. Граница, здания, землепользование, привязки и матрица уже восстановлены.
Ячейка `metric-map-selector` для экспорта не нужна. При отключённых интерактивных картах
список школ и таблицы доступны в Jupyter, карта кварталов — в автономном HTML.

Для маршрутов задайте `ROUTE_CHECK_PAIRS = [(source_id, target_id), ...]` перед §12.1.
В §13 `save-summary` уже добавлены четыре вывода по текущим таблицам: покрытие застройкой
и максимальный FSI, морфотипы Strelka, доступность и школьная модель. Числа подставляются
при выполнении ячейки; собственные выводы добавляйте в конец списка `OBSERVATIONS`
в этой же ячейке. После её выполнения пересоберите HTML, чтобы показать новый текст.
Выбранные пары сами по себе ещё не означают проверку на местности.

## Создать HTML

Для нового представления **имеющегося** снимка можно сразу выполнить первую команду,
не открывая ноутбук. Чтобы включить пропущенные поля на карте, сначала пройдите маршрут 2;
чтобы получить исправленный школьный сценарий — маршрут 3.

```bash
.venv/bin/python examples/create_dashboard.py
open examples/data/lodeynoye_pole/results/dashboard.html
```

Скрипт использует стандартную библиотеку Python, читает локальные результаты и
`prepared/`, проверяет контрольную сумму локального GraphML без расчёта маршрутов.
Он не запускает ноутбук и не делает сетевых запросов. Результат — один автономный
`examples/data/lodeynoye_pole/results/dashboard.html` со встроенными данными, SVG-картой
и CSV. При ошибке сверки сначала обновите указанные зависимые ячейки и повторите сборку.

Сохраняйте вместе ноутбук и всю папку `examples/data/lodeynoye_pole/`, включая `*.meta.json`.
Для сравнения с контрольными числами из начала инструкции сбросьте фильтры карты и поиск
в таблице. После изменения школьной выборки прежние 1500 мест и 83,01% не являются
ожидаемыми контрольными значениями нового сценария.
